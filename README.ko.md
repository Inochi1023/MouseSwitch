# MouseSwitch

노트북과 데스크톱을 마우스 하나(+키보드)로 번갈아 쓰는 프로그램입니다.
마우스 옆 버튼을 한 번 누르면 조종 대상이 반대편 PC로 넘어갑니다.

- 같은 와이파이/랜(같은 공유기) 안에서만 동작합니다. 인터넷 너머로는 연결되지 않습니다.
- 첫 연결 때 6자리 페어링 코드로 인증하고, 그 뒤로는 암호화된 상태로 자동 연결됩니다.
- 윈도우를 켜면 자동으로 실행되게 만들 수 있습니다.
- 두 PC 모두 Windows 10/11 (64비트) 기준입니다.

---

## 1. 설치 (두 PC 모두)

설치 프로그램이 없습니다. 폴더를 통째로 복사해서 쓰면 됩니다.

1. `MouseSwitch` 폴더를 두 PC 모두에 복사합니다. (예: `C:\MouseSwitch`)
2. 각 PC에서 `build.bat` 더블클릭 → `MouseSwitch.exe` 가 만들어집니다.
   - 윈도우에 원래 들어있는 컴파일러를 쓰기 때문에 따로 설치할 게 없습니다.
   - 오류가 나면 창에 뜬 메시지를 그대로 복사해서 알려주세요.
3. `설치_방화벽+자동시작.bat` 을 오른쪽 클릭 → 관리자 권한으로 실행합니다.
   - 방화벽 구멍(24800/24801)을 열고, 로그인할 때 관리자 권한으로 자동 실행되게 등록합니다.
   - 게임 화면 위에서도 제대로 동작하려면 관리자 권한이 필요합니다. 이 단계를 건너뛰면
     일부 프로그램에서 버튼/키 입력이 먹지 않을 수 있습니다.

---

## 2. 연결하기 (한 번만)

### 조종받는 PC (예: 노트북)
1. `MouseSwitch.exe` 실행 → 설정 창이 뜹니다.
2. "조종을 받는 PC" 선택 → [저장]
3. [페어링 코드 만들기] → 화면에 6자리 숫자가 크게 뜹니다. (3분간 유효)

### 마우스가 꽂힌 PC (예: 데스크톱)
1. `MouseSwitch.exe` 실행 → 설정 창.
2. "마우스·키보드가 꽂혀 있는 PC" 선택.
3. [검색] → 같은 네트워크의 노트북이 목록에 뜹니다. 선택하면 IP가 자동으로 채워집니다.
   - 안 뜨면 노트북의 IP를 직접 입력하세요. (노트북에서 `Win+R` → `cmd` → `ipconfig`)
4. 전환 버튼: 마우스 옆 버튼 앞/뒤 중 원하는 걸로. (휠 클릭, 단축키만도 가능)
5. 키보드도 함께 넘기기: 체크하면 마우스와 키보드가 같이 넘어가고,
   체크를 풀면 마우스만 넘어가고 키보드는 데스크톱에 남습니다.
6. [저장] → [페어링 시작] → 노트북에 뜬 6자리 코드 입력.
7. "페어링 완료" 가 뜨면 끝입니다.

이후에는 두 PC 모두 전원을 켜면 알아서 다시 연결됩니다.

---

## 3. 쓰는 법

- 마우스 옆 버튼 한 번 → 조종 대상이 반대편 PC로. 한 번 더 누르면 돌아옵니다.
- Ctrl + Alt + S → 같은 기능 (마우스 버튼이 안 먹을 때를 위한 비상 단축키).
- Ctrl + Alt + K → 키보드 넘기기 켜기/끄기. 삑삑 두 번 (높은음=켜짐, 낮은음=꺼짐).
  트레이 아이콘 우클릭 메뉴나 설정 창 체크박스로도 바꿀 수 있고, 누르는 즉시 적용·저장됩니다.
- 전환될 때 짧은 알림음이 납니다. (설정에서 끌 수 있음)
- 트레이 아이콘 색: 회색=연결 안 됨 / 초록=연결됨(내 PC 조종 중) / 주황=상대 PC 조종 중
- 트레이 아이콘에 마우스를 올리면 현재 상태와 지연시간(ms)이 보입니다.

### 안전장치
- 연결이 끊기면 조종권이 자동으로 원래 PC로 돌아옵니다. 마우스가 없어지는 일은 없습니다.
- 넘어간 쪽에서 키가 눌린 채로 연결이 끊겨도, 자동으로 전부 떼어줍니다. (게임에서 계속 걷는 현상 방지)
